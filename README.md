A token launch radar: 178 pre-token protocols ranked by implied value, each with a concrete farm plan. The model (radar-2) scores every row from the snapshot's own figures — TVL, seven-day growth, age with no token, and chain reach — with no protocol name special-cased. The dashboard is sortable and filterable, shows the model breakdown for every protocol, and lets you retune the model live in a sandbox.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
